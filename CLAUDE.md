  do and why, in simple English.
- Only create or change files inside E:\it-support-portfolio.
- Never change settings on my PC: no installs, no Windows features, no
  network, firewall or registry changes.
- Scripts must be safe: read-only diagnostics, except "flush DNS" and
  "renew IP", which must ask me for confirmation first.

  Use placeholders like <PASSWORD>.

- Don't delete anything without asking me.
