## Summary

The user needs Microsoft Visio to draw process diagrams for the logistics project. The manager has agreed. The user offered a cost centre if needed.

## Troubleshooting steps

This is a request, not a fault, so the steps follow the approval process.

1. **Check the approval.** Confirm that the manager agreed. Ask for written approval on the ticket, and ask for the cost centre.
2. **Check the licence.** Is a Visio licence free in the licence pool, or must one be bought?
3. **Check the PC.** Is it a company PC that meets the requirements, with enough disk space?
4. **Check for alternatives.** Is a free or already licensed tool enough (for example a browser-based diagram tool)? Mention it to the user.

## Root cause

Not applicable (software request). The user did not have a licence for Visio.

## Resolution

1. Get the manager's written approval and the cost centre.
2. Assign a Visio licence to the user's account.
3. Install Visio on the user's PC through the company's software tool or deployment method.
4. Open Visio with the user, check that it activates, and let the user draw a test diagram.
5. Update the licence register with the user, date and cost centre.

## Prevention

- Offer a software catalogue with standard requests and approval rules, so users know the steps.
