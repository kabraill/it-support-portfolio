# Why can't I save this file type?

**Applies to:** the shared company folder (**Z: Shared**).

## What is happening?

To keep the shared folder tidy, safe and fast, IT blocks some kinds of files. If you try to save a blocked file, Windows shows a message such as:

> **Destination Folder Access Denied. You need permission to perform this action.**

This does not mean that you did something wrong, and it does not mean that your account is broken. The folder simply does not accept that file type.

## Which files are blocked?

| Type | Examples |
|---|---|
| Pictures | .jpg, .png, .gif, .bmp |
| Programs | .exe, .msi, .bat |
| Audio and video | .mp3, .wav, .mp4, .avi |

Documents such as Word, Excel, PowerPoint and PDF files are allowed.

## Why do we block them?

- **Security:** program files can contain viruses.
- **Space:** pictures and videos are large and fill up the shared folder quickly. The folder also has a **size limit (quota)**.
- **Order:** the shared folder is for working documents.

## What can I do?

1. **Put the picture in a document.** For example, insert it into a Word or PowerPoint file and save that file.
2. **Save it somewhere else.** Use your own PC's local folder, or the storage that IT recommends for pictures.
3. **Make the file smaller** if it is a space problem. Delete old files you no longer need.
4. **Ask the help desk** if you really need to store this file type for your work. Tell us why. If your manager agrees, we can look for a solution.

## The error says the folder is full

The shared folder has a size limit. If you see a "not enough space" message while your PC has plenty of free space, the shared folder itself may be full. Delete files you no longer need, then try again, and tell the help desk if the problem stays.

## Contact the help desk when

- you are not sure why a file is blocked
- you need an exception for your work
- you see "not enough space" in the shared folder
